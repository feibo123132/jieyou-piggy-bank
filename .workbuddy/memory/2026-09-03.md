### 设计选择
- **chip 颜色与现有交易 tag 的 tone 对齐**：necessary=blue / optional=orange / unnatural=rose，调用者一眼能识别同一档位
- **view mode 用纯色 dot**（`bg-blue-500 / bg-orange-500 / bg-rose-500`），不显示 icon——避免列表项视觉过载
- **list 项后端 shape**：保留可选 `category` 字段，向后兼容老 `{ id, label, amount }` 数据；通过 `?? 'necessary'` 业务读取处统一兜底
- **grid 不动**：DashboardPage 卡片 2+3 grid 不变，但每张卡的算法换了；卡片标题、配色、布局零变更
